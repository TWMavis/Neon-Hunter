# 霓虹獵手 NeonHunter

賽博龐克像素風、2D 橫版平台、反轉版吸血鬼倖存者：你追著會逃跑的流氓 AI 跑。
完整企劃見 [docs/DESIGN.md](docs/DESIGN.md)。

用 Godot 4.7 開啟資料夾，按 F5 執行。

## 目前進度：M2（第 1 區段可以完整爬完）

只帶小刀出發 → 第 1～4 層（每層 3～5 分鐘）→ 每層之間在電梯換晶片、選路線 → 第 5 層 Boss「回收巨獸」→ 區段完成。
死亡就回到區段起點重新攀登。

| 按鍵 | 功能 |
|---|---|
| A / D | 左右移動 |
| 空白鍵 | 跳躍（按越久跳越高）；移動槽插了對應晶片時可二段跳、牆跳、按住滯空 |
| S | 從單向平台（粉紅色）往下跳 |
| Shift | 朝 WASD 方向衝刺（衝刺中無敵） |
| F（按住 2 秒） | 在電梯裡按住，離開這層樓（避免誤觸） |
| 滑鼠 | 360° 瞄準 |
| 左鍵（按住） | 主武器 |
| 右鍵 | 副武器 |
| 1 / 2 / 3 | 三選一卡片 |
| 長按 Tab | 打開晶片頁面（消耗 10% 電量） |
| R | 死亡後重新攀登 |
| Esc | 放開／鎖回滑鼠 |

### 一層樓

電梯門打開 → 獵殺流氓 AI 湊權限碎片（配額每層 +2）→ 電梯解鎖 → 4:00 清除協議 → 5:00 殺不死的追獵者。
電量每秒下降、擊殺回復；回到電梯電量回滿。
電量歸零時進入**超頻模式**：攻擊力加倍、倒數 10 秒、電量不會自然消耗，時間到時電量還是 0 才真的死亡。每次攀登 3 次機會（電量條旁邊的橘色菱形）；電量超過上限的部分累積到電量條下方的橘色超頻條，滿了回復一次機會。

### 武器

開場只有一把**小刀**（左鍵近身揮砍，範圍內全部砍到並擊退），右鍵是空的。
槍和右鍵武器從升級三選一（還拿著小刀或右鍵空著時，保證有一張武器卡）、電梯商店（每次賣一把，左鍵 60、右鍵 50 信用點）取得。
拿到新武器會取代同一邊的舊武器，舊武器上能插的晶片和分配的額度會跟著移過去。

| 左鍵 | 右鍵 |
|---|---|
| 脈衝步槍：中距離連射 | 電磁網：定身 2 秒 |
| 霰彈槍：近距離、擊退 | 鉤爪砲：拉獵物過來，或把自己拉向牆 |
| 追蹤飛鏢：會轉彎 | EMP 手雷：拋物線、範圍緩速 |

### 升級與晶片（類空洞騎士護符）

- 擊殺掉藍色資料晶片（經驗），升級時三選一：新晶片、晶片強化（+1、+2）、新被動技能
- **每個技能（2 把武器、移動槽、每個被動）各有自己的額度**；移動類晶片（衝刺電容、疾行馬達、彈簧腿、衝刺迴路、幽靈迴路、二段跳、牆跳、推進器滯空）只能插在移動槽
- **總晶片額度**開局 9 格（左鍵、右鍵、移動槽各 3），每升一級 +1、打倒 Boss +1；用技能旁的 ＋／－ 自由分配，總和不會超過總額度
- **長按 Tab** 在樓層中打開晶片頁面（遊戲暫停，消耗 10% 電量）；電梯裡調整免費
- 晶片插在哪個技能上就只強化那個技能；電量、拾取範圍、衝刺次數這類全身數值插在哪都一樣
- 技能還剩 1 格就能插，超出的部分算**超載**（任一技能超載，電量消耗加倍）
- 16 枚晶片：通用、專屬（只能插在對應武器或被動）、傳說、黑市（便宜但有副作用）；每枚晶片會寫「可插在」哪些技能
- 4 組共鳴（不會事先告訴你）：發現後記錄在電梯的共鳴列表
- 樓層內拿到的新晶片會自動插進空位最多的合適技能，放不下就進背包
- 在電梯裡點一枚晶片選取，再按技能旁的「插到這裡」就能移過去；「卸下選取的晶片」放回背包

### 4 格被動

僚機無人機、電漿光環、雷達掃描、護盾產生器。（二段跳、牆跳、推進器滯空改成移動槽晶片）
沒有雷達時，畫面邊緣只指出 320px 內的獵物。

### 獵物

資料鼠、偵查無人機（飛）、跳躍者（第 2 層起）、複製體（第 3 層起，12 秒沒殺就分裂）、
裝甲運輸車（精英，掉寶箱）、金色獵物（限時登出）、Boss 回收巨獸（每掉 1/4 血就鑽進垃圾堆，從別的堆冒出來並叫小弟）。
地面獵物用平台導航圖逃跑：往「離玩家最遠的相鄰平台」走、跳、往下鑽，會被逼進死角。

### 電梯路線

每次二選一：一般層 + 隨機一種特殊層（危險層、維修層、黑市層、金庫層）。第 4 層之後固定是 Boss 層。

### 電梯商店

擊殺獵物和通關樓層會得到信用點（右上角）。電梯的「商店」分頁每次隨機賣 4 枚晶片，買到已持有的晶片會升一級；可以花信用點刷新商品（15 起，每多刷一次 +5），或花購買價 1.5 倍直接強化已持有的晶片。

## 檔案結構

```
autoload/       GameInput（輸入）、RunState（本層：電量、碎片、時間）、ClimbState（攀登：等級、晶片、被動）
data/           FloorData、ChipData、SynergyData、Catalog（資料表）、maps/（地圖）
scenes/menu/    攀登起點（選武器）
scenes/game/    一層樓：生怪、時間軸、掉落、升級
scenes/elevator/ 電梯中場：換晶片、商店、選路線
scenes/player/  玩家、被動技能、僚機
scenes/weapons/ 6 把武器、子彈
scenes/enemies/ 獵物、追獵者
scenes/world/   地形、平台導航圖、電梯、背景、雨
scenes/ui/      HUD、三選一卡片、晶片頁面、商店、主題
scripts/        Art（畫像素圖）、Audio（音效與音樂）、碰撞層、字型
art/  audio/    產生出來的像素圖與音檔
tools/          素材產生器、精靈圖預覽
tests/          冒煙測試、升級畫面預覽
```

像素圖、音效、音樂都由 `tools/generate_assets.gd` 產生（字元圖與波形合成，沒有外部素材），來源與授權見 [docs/CREDITS.md](docs/CREDITS.md)。
改圖或改音後重新執行：`Godot_v4.7.2-stable_win64_console.exe --headless --path . --script res://tools/generate_assets.gd`
