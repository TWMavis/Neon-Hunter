# 潛行狀態

> **狀態**：已實作（按住潛行、背後增傷）。下面「之後可以加的晶片」還沒做。
> 跟草案不同的一點：**背後 ×1.5 對所有小刀攻擊都有效**（不限潛行），潛行一擊從背後出手就是 ×2.5 × 1.5。

## 一句話

按住潛行鍵壓低身子慢慢接近，獵物要靠得更近才會發現你；從潛行中出手的近戰攻擊傷害大增。適合在牠們逃跑前先摸上去「先手一刀」，也讓開場只有小刀時有更好的打法。

## 進入與離開

| 項目 | 建議 |
|---|---|
| 按鍵 | 按住 **C**（設定畫面可改）；手把按住 **LB**（目前 LB 是右鍵武器的備用鍵，改由 LT 單獨負責） |
| 進入 | 站在地上按住就進入；空中不能進入 |
| 移動速度 | 50%（不能衝刺、不能跳；跳躍或衝刺會直接解除潛行） |
| 解除 | 放開按鍵、跳躍、衝刺、被打中、開槍（槍聲） |
| 重新進入 | 解除後 0.6 秒才能再潛行，避免「潛行 → 砍 → 潛行」無限連打 |

## 效果

| 效果 | 數值 | 說明 |
|---|---|---|
| **近戰傷害增加** | 潛行中出手的近戰 ×2.5 | 和「喘息／被網住 ×2」「超頻 ×2」相乘；出手後潛行解除（觸發重新進入的 0.6 秒） |
| **獵物戒心降低** | 感知範圍 ×0.35 | 例：資料鼠 130 → 約 45px，金色獵物 200 → 70px |
| 無聲擊殺 | 潛行一擊殺死時不觸發恐慌傳染 | 可以一隻一隻清，不會整群逃散 |
| 背後加成（可選） | 從獵物背後出手再 ×1.5 | 獵物面向的反方向；讓走位更重要 |

不影響的東西：電量照常消耗（潛行比較慢，本身就是代價）；已經在逃跑的獵物不會因為你潛行就冷靜下來。

## 跟現有系統的互動

| 系統 | 互動 |
|---|---|
| 逃跑 AI | 遊蕩中的獵物只有在縮小後的感知範圍內才會發現你；已經在逃的照常逃 |
| 各自的反擊 | 只有「已經發現你」的獵物會反擊：風箏手不會射、無人機不會投彈、裝甲運輸車不會衝撞 |
| 金色獵物 | 閃現距離 55px 不變，但牠要靠很近才發現你，潛行是最穩的抓法 |
| Boss、追獵者 | 不受潛行影響（Boss 感知 400、追獵者本來就殺不死） |
| 超頻 | 可以潛行，近戰傷害 ×2.5 × 2 疊加 |
| 槍 | 開槍會解除潛行（之後可以用晶片「消音模組」改變） |

## 視覺與音效

- 玩家半透明、顏色變暗，腳下一圈淡淡的「聲音範圍」圓圈（= 縮小後的感知範圍參考）
- 獵物頭上的提示：靠近但還沒發現時出現「?」，發現時「!」並播放警覺音效
- HUD 左下角顯示「潛行中」；潛行一擊出手時有專屬的斬擊特效和音效

## 之後可以加的晶片（插在移動槽）

| 晶片 | 額度 | 效果 |
|---|---|---|
| 暗影步 | 1 | 潛行移動速度 50% → 75% |
| 處決協定 | 2 | 潛行近戰傷害再 +50%，潛行一擊殺死回電 ×2 |
| 消音模組 | 2 | 開槍不會解除潛行（插在武器上） |
| 光學迷彩 | 3 | 感知範圍 ×0.35 → ×0.2 |

## 實作範圍（確認後做）

1. 輸入：新增「潛行」動作（C／手把 LB），加進設定畫面的改鍵清單

3. 獵物：感知範圍依潛行縮小、「?」「!」提示、只有發現玩家後才反擊
4. 武器：小刀的潛行一擊傷害、無聲擊殺不觸發恐慌
5. HUD、音效、測試、文件
6. （可選）四枚潛行晶片
